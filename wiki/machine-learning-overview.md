## 概率与学习任务（P5–39）

- 概率基础：随机变量、伯努利/二项/高斯分布、密度、CDF、联合/条件/边缘分布、采样、期望、大数定律，见[采样与期望](probability-sampling-expectation.md)。
- 监督学习：有输入和目标标签，典型任务为分类、回归。
- 无监督学习：无额外给定标签，典型任务为聚类、降维、密度估计。
- 强化学习：通过交互与奖励，学习提高期望累积回报的行为。
- 四要素：数据、模型、学习准则、优化算法。数据通常记为 $D=\{(x^{(n)},y^{(n)})\}_{n=1}^N$，预测可以输出数值，也可以输出条件分布。

## 损失、风险与优化（P40–49）

| 量 | 定义及含义 |
| --- | --- |
| 单样本损失 | $\mathcal L(y,f_\theta(x))$ |
| 期望风险 | $R(\theta)=\mathbb E_{(x,y)\sim P}[\mathcal L(y,f_\theta(x))]$，目标总体的平均损失 |
| 经验风险 | $\hat R_D(\theta)=\frac1N\sum_n\mathcal L(y^{(n)},f_\theta(x^{(n)}))$，训练样本平均 |
| ERM | $\theta^*=\arg\min_\theta\hat R_D(\theta)$ |

梯度下降：$\theta_{t+1}=\theta_t-\alpha_t\nabla\hat R_D(\theta_t)$。学习率过小会缓慢，过大可能震荡或发散。

| 更新方法 | 每次使用数据 | 主要特点 |
| --- | --- | --- |
| 全批量 GD | 全部样本 | 当前经验风险的全梯度，单次成本较高 |
| 单样本 SGD | 一个随机样本 | 成本小、梯度有噪声 |
| Mini-batch SGD | 一小批样本 | 兼顾成本与并行 |

不能仅凭“迭代足够多”保证 SGD 收敛到局部最优；目标性质、步长和噪声条件都重要。精确求解与实际迭代的区别见[优化边界](model-complexity-generalization-optimization.md#理论最优与实际优化)。

## 泛化与正则化（P51–56）

课件以 $R(f)-\hat R_D(f)$ 描述泛化差距；其他材料也可能用“泛化误差”指总体风险，必须先看定义。

显式正则化目标为 $\hat R_D(\theta)+\lambda\Omega(\theta)$。提前停止通过验证集选择训练停止位置，实际可设置耐心轮数并保留验证表现较好的参数。验证集、交叉验证是选择工具，并非单独保证泛化改善的方法。

## 回归与概率视角（P58–82）

- [线性回归、秩与求导](linear-regression-matrix-calculus.md)：正规方程、唯一性、岭回归、矩阵链式法则。
- 多项式回归是固定非线性特征上的线性参数模型，仍能用最小二乘方法。
- [似然与损失](likelihood-loss-inductive-bias.md)：高斯噪声连接 MLE 与最小二乘；高斯先验连接 MAP 与 L2 惩罚。
- $\arg\min$ 返回最优参数，不是最小损失值。最优解存在、是否唯一与算法是否找到它是三个问题。

## 模型选择与偏差—方差（P84–91）

训练集学参数，验证集选设置，测试集最终评估。交叉验证按跨折平均表现选择设置，不是选择最好的一折。

$$
\mathrm{AIC}=2k-2\log\hat L,\qquad
\mathrm{BIC}=k\log N-2\log\hat L
$$

$k$ 为估计参数数量，$\hat L$ 为拟合后的最大似然，通常选准则较小者；各有适用条件，并非任意任务上无条件有效。

平方损失的期望预测误差可分为偏差平方、训练集变化引起的预测方差与不可约噪声，公式及条件见[泛化笔记](model-complexity-generalization-optimization.md#泛化曲线和数据量理论支持的范围)。集成取平均可降低不完全相关的预测波动；收益取决于模型间相关性。

## 学习理论与假设（P93–98）

| 概念 | 主旨与边界 |
| --- | --- |
| 没有免费午餐 | 相应问题集合与平均假设下，没有普遍占优的算法；不是说实际算法无法比较 |
| 丑小鸭定理 | 在对属性同权、对称处理等设定下，相似性无法自然偏向日常分类；特征和权重的选择重要 |
| 奥卡姆剃刀 | 解释能力相当时避免多余复杂性，不是简单模型总是更好的保证 |
| 归纳偏置 | 模型、先验、学习过程对规律的假设或偏好 |
| PAC 与样本复杂度 | 在明确概率与精度要求下研究学习所需样本，详见[已有页的扩展](model-complexity-generalization-optimization.md#pac与样本复杂度) |

朴素贝叶斯假设给定类别后特征条件独立，不是无条件独立。PAC 的置信度不是准确率，经验与期望风险接近也不意味着两者都小。
