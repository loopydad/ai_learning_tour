# 模式识别与机器学习绪论

创建：2026-10-28｜更新：2026-10-28

## 这讲解决什么问题

机器学习从有限数据中学习规律，目标是对未见数据作出有效预测。课件以多项式曲线拟合串起一条主线：

**数据 → 模型 → 损失函数 → 参数优化 → 验证集选择模型 → 测试集评估泛化。**

## AI、模式识别与机器学习

| 概念 | 含义及侧重点 |
| --- | --- |
| 人工智能 AI | 让机器表现出智能行为，涉及感知、语言、学习、记忆与决策等 |
| 模式识别 PR | 自动发现数据中的模式和规律，并用于分类等操作；更偏应用全流程 |
| 机器学习 ML | 从有限观测数据中学习具有一般性的规律；更关注学习机制 |

课件将模式识别与机器学习视为高度重合的领域；上述侧重点是概括，并非严格的学科边界。

背景：1956年达特茅斯会议是人工智能学科诞生的标志；图灵测试通过问答考察机器能否表现出难以与人区分的智能行为。现实任务难以穷尽人工规则，是采用机器学习的重要动机。

## 学习任务

| 类型 | 数据或反馈 | 任务与例子 |
| --- | --- | --- |
| 监督学习 | 输入及目标标签 | 分类：数字识别、垃圾邮件检测；回归：连续数值预测 |
| 无监督学习 | 无给定目标标签 | 聚类、密度估计、特征抽取和降维 |
| 半监督学习 | 有标注与无标注数据 | 结合两类数据学习 |
| 自监督学习 | 从数据自身构造监督信号 | 用监督目标学习无人工标注数据 |
| 强化学习 | 环境交互和奖励反馈 | 围棋、行为决策 |

分类预测类别，回归预测连续数值；聚类寻找分组结构，没有预先给定的类别标签。自动驾驶等系统可以同时涉及多种任务。

## 用多项式理解学习过程

训练集为 $D=\{(x^{(n)},y^{(n)})\}_{n=1}^{N}$，本例输入、输出均为实数。选取模型：

$$
f(x,\mathbf w)=\sum_{j=0}^{M}w_jx^j
$$

$M$ 为阶数，参数向量 $\mathbf w\in\mathbb R^{M+1}$。用平方误差衡量拟合：

$$
E(\mathbf w)=\frac12\sum_{n=1}^{N}[f(x^{(n)},\mathbf w)-y^{(n)}]^2,
\qquad \mathbf w^*=\arg\min_{\mathbf w}E(\mathbf w)
$$

$\arg\min$ 给出使损失最小的参数，而不是最小损失值。MSE 是平方误差的样本平均；不含其他损失项时，将目标乘以正常数不改变最优参数。

机器学习四要素：**数据、模型、学习准则、优化算法**。它们分别回答“学什么材料、用什么形式、怎样判断好坏、怎样求解”。

## 泛化、欠拟合和过拟合

泛化能力指模型预测新数据的能力；训练与新数据之间的表现差异称为泛化差距。二者不能混作同一个定义。

| 状态 | 典型表现 |
| --- | --- |
| 欠拟合 | 模型未捕捉主要规律，训练和新数据表现均差 |
| 拟合适当 | 捕捉主要规律，新数据表现较好 |
| 过拟合 | 对训练样本拟合很好，但对新数据表现较差 |

课件例子中，$M=0,1$ 太简单，$M=3$ 较合适，$M=9$ 出现剧烈摆动。这是具体数据上的示例，不是关于这些阶数的普遍定理。

**不能只根据训练误差最低选择模型。** 最优训练误差、实际训练误差和新数据误差的区别，见[数学边界笔记](model-complexity-generalization-optimization.md)。

## 正则化与数据量

课件通过 L2 正则化惩罚大系数：

$$
J_\lambda(\mathbf w)=E(\mathbf w)+\frac\lambda2\|\mathbf w\|_2^2,
\qquad \lambda\geq0
$$

正则化控制参数，不必改变多项式阶数。$\lambda$ 太小可能约束不足，太大可能欠拟合；是否改善泛化要用验证数据判断。

图中的 $\ln\lambda=0$ 对应 $\lambda=1$；$\ln\lambda\to-\infty$ 才对应 $\lambda\to0^+$。

课件固定九次多项式，对比 $N=15$ 和 $N=100$，展示更多数据下拟合更稳定。增加有代表性的数据通常有帮助，但不保证每次实际测试误差都下降。

## 模型选择

| 数据集 | 职责 |
| --- | --- |
| 训练集 | 学习参数，例如系数 $\mathbf w$ |
| 验证集 | 选择模型及超参数，例如 $M$、$\lambda$ |
| 测试集 | 模型确定后评估最终表现，不参与调参 |

$S$ 折交叉验证：将用于训练和模型选择的数据分为 $S$ 份，每次用 $S-1$ 份训练、1份验证，轮换 $S$ 次，按平均验证表现选择模型设置。选择的是设置，不是表现最好的一折；最终测试集仍应独立保留。

课件的总结是 **ML = Optimization + Generalization**：既要学好训练数据，也要在新数据上有效。
