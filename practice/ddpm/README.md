## 方法与分母

数据为 CelebA 对齐裁剪人脸图片，共 202599 张；读取 RGB，短边缩放并中心裁剪为
104×104，映射到 [-1,1]。不读取属性或身份标签，进行无条件生成。
固定划分种子 42，留出验证 1024 张、训练 201575 张；未使用官方划分，人物身份不保证互斥。

训练：每张图片均匀抽取 t∈{1,…,1000} 和标准高斯噪声，构造带噪图并预测累计噪声。
损失对样本及全部像素通道求均方误差；每轮指标按图片数加权汇总，包含末批。
验证模式禁用梯度、使用固定噪声随机种子 1234；验证顺序和批大小不变时便于逐轮比较。

配置：batch size 8，线性 beta 从 1e-4 到 0.02，Adam 学习率 1e-4，梯度范数上限 1.0。
U-Net 约 69 万参数，无 Attention；可学习时间 Embedding。采样使用完整 1000 步、固定后验方差，
最后一步不再加噪。未进行 FID 等生成分布质量评估。
