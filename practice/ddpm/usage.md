# 手写 DDPM：运行说明

创建：2026-10-30｜更新：2026-10-31

`ddpm.py` 是用户手写的 DDPM 学习实现，包含 Codex 辅助的部分工程支持；
`dataloader.py` 由 Codex 实现数据读取。不将本项目表述为完全独立完成。
依赖：PyTorch、NumPy、Pillow。图片缩放、裁剪直接使用 Pillow，不依赖 torchvision。

当前实验已在服务器完成 40 轮；配置、损失、图片与限制统一见 [实践记录](README.md)。
本页后面的验证段落是各次检查的历史范围，早期“未运行训练”不代表最终实验状态。

## 准备图片

2026-10-30 已由 Codex 下载并解压 CelebA 对齐裁剪版，共 202,599 张 JPG。
实际下载自 Hugging Face 镜像；来源、校验值与验证范围见
[数据来源记录](../../sources/ddpm/celeba.source.md)。

默认数据目录为 Wiki 根目录下的 `sources/ddpm/data/img_align_celeba/`，其内直接存放 JPG 图片。
也可以修改 `ddpm.py` 的 `data_root`，指向已有图片目录，无需复制数据。

## 使用

运行 `python /Users/gary/Documents/ChatGPT/ai_learning_tour/practice/ddpm/ddpm.py`
会打印首批信息并开始训练，默认总目标为 100 轮。数据迭代返回图片张量，而非 `(图片, 标签)`。

- 输出：float32，形状 `[B, 3, 104, 104]`，范围 `[-1, 1]`。
- 预处理：转 RGB → 短边缩放到 104 → 中心裁剪 → 转张量并归一化。
- `image_size`、`batch_size` 可在入口修改；末批可能不足 8 张。
- 读取目录下所有 JPG/JPEG/PNG，不递归、不使用标签。训练入口按固定种子随机划分训练/验证图片，未使用官方划分。
- 默认 `num_workers=0`；以后需要多进程时，在 `main()` 内创建 loader 并调高该参数。
- 数据保留在 CPU，训练时由你用 `x0.to(device)` 移到模型所在设备。

参考：[RethinkFun/DDPM 数据加载部分](https://github.com/RethinkFun/DDPM/blob/main/ddpm.py)。
这是为当前练习编写的数据入口，不是原仓库文件副本。

## 最小训练支持

- 批次日志：首批、末批及每 `log_every=100` 批打印损失。
- 梯度裁剪：反向传播后将梯度总范数限制到 `max_grad_norm=1.0`；遇到非有限梯度报错停止。
- 断点续训：默认 `resume=True`，存在 `outputs/latest.pt` 时恢复模型、Adam 状态和已完成轮数。
  `num_epochs` 是总目标轮数；恢复时学习率沿用检查点的优化器状态。
- 每轮结束保存一次，先写临时文件再替换旧检查点。中途停止会丢失当前未完成轮的进度。
- 重新实验：设置 `resume=False`，并使用新的 `output_dir` 以保留旧结果。
- 恢复时检查图片尺寸与噪声调度是否一致；不保存随机数状态，不保证中断前后逐步数值一致。

## 验证损失

`val_size=1024`、`split_seed=42`：固定留出 1024 张图片，其余用于训练。
保持图片目录内容不变，即可复现划分。划分按图片进行，不保证人物身份互斥。
每轮打印 `train_loss` 与 `val_loss`，同时保存在最新检查点中。

验证使用 `model.eval()`、禁用梯度，不更新参数；按图片数加权平均噪声预测 MSE，
最后不足一个批次的图片也计入。固定验证时间步与噪声随机种子，在图片顺序与批大小
不变时便于逐轮比较。验证期间使用独立随机数生成器。
这是用于开发时观察的验证集，不是最终独立测试集；噪声 MSE 也不等于生成图片质量。

旧版检查点曾使用全部图片训练，无法作为新验证集上的独立评估起点，程序会拒绝续训。
请更换 `output_dir` 开始新实验；新版检查点支持相同划分下续训。
